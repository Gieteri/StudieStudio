# StudieStudio
StudieStudio is ontstaan vanuit een duidelijke wens: het leren voor de middelbare school overzichtelijker, effectiever en leuker maken. Door complexe theorie om te zetten in duidelijke samenvattingen, oefenvragen en handige flashcards, geven we scholieren de handvatten die ze nodig hebben om echt te begrijpen wat ze leren.
